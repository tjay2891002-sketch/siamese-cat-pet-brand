# 用品与家居

围绕「鲜食 + 用品一站式」的品牌定位，客服在回答用品问题时需结合猫咪年龄、毛发状态、家庭环境给出组合建议，并在合适时引导凑单。

## 猫砂与猫砂盆

- 膨润土：结团快、除味好，是多数家庭首选；对粉尘敏感或幼猫可优先选低尘款。
- 豆腐砂/混合砂：可冲马桶、粉尘更少，适合租房或对粉尘敏感的家庭。
- 猫砂盆数量建议：猫数 + 1。多猫家庭建议一只一盆，并放在安静、通风、互不干扰的位置。
- 猫砂厚度建议 5–7 cm，日常至少每日铲 1–2 次，每 2–4 周整盆更换并清洗。
- 如果猫咪突然乱尿，优先排查猫砂盆清洁度、摆放位置、是否临近换粮期或应激源。

## 梳毛与毛发护理

- 短毛猫每周 1–2 次梳毛；长毛猫建议每日梳理，重点清理耳后、腋下、腹部打结。
- 掉毛季（春秋）可增加梳毛频率，搭配鱼油或含 Omega-3 的鲜食，帮助毛色更顺亮。
- 梳理顺序：从背部、侧腹到尾部，顺应毛流，避免用力拉扯。
- 指甲剪建议每 2–3 周修剪一次，只剪透明尖端，避开血线。
- 梳毛护理套装可随鲜食一起凑单配送，减少单独下单的等待。

## 猫窝、玩具与丰容

- 猫窝选择：半封闭式能给安全感，开放式更透气；冬季加一层软垫更保暖。
- 互动玩具：逗猫棒、羽毛棒能模拟猎物，建议每天 10–15 分钟，让猫咪保持活动量。
- 丰容技巧：将冻干小方藏在玩具或纸箱里，激发觅食天性，减少无聊引起的拆家。
- 多猫家庭建议提供多个躲藏点、高处攀爬位，减少资源竞争。

## 喂食器具

- 建议使用不锈钢或陶瓷碗，避免塑料碗藏垢引发黑下巴。
- 餐具每天清洗，鲜食为主时注意餐具干燥，防止细菌滋生。
- 自动饮水机可增加饮水量，但需定期更换滤芯并清洗水箱。

## 新手家庭开箱清单

- 入门推荐：猫砂 + 猫砂盆 + 互动玩具 + 一份鲜食试吃包。
- 进阶推荐：梳毛护理套装 + 猫窝 + 冻干小方，搭建完整的「吃 + 用 + 玩」闭环。
- 所有用品均可随鲜食一起凑单配送，一次冷链到家更省事。

## 政策与服务

- 用品与鲜食在同一次冷链订单配送，不影响鲜食保质期。
- 用品如存在质量问题，支持 7 天内退换；具体以售后退款政策为准。
- 客服可结合猫咪档案，为用户搭配「鲜食 + 用品」的个性化方案。
